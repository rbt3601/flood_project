# Dataset Decision

## Final Topic
CNN-Based Flood Damage Assessment from Satellite Imagery Using Semantic Segmentation

## Selected Dataset
SpaceNet 8

## Why Selected
We selected SpaceNet 8 because it directly matches the project goal of flood damage assessment using semantic segmentation. It provides pre-event and post-event satellite imagery along with labels related to flooded buildings and roads.

## Expected Use
- pre-event image
- post-event image
- label/annotation file
- train/validation/test pipeline
